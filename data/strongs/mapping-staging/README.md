# Strong's Mapping Staging

Generated KJV-to-Strong's mapping files can be placed here while they are under
review.

Rows in this folder are not included in the public lookup index. Promote only
manually reviewed rows into `data/strongs/mapping-batches/`, then rebuild the
public index with:

```bash
npm run build:strongs-mapping-index
```

Do not commit raw source files or unreviewed full-Bible exports here.
