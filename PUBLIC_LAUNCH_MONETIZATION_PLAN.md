# Public Launch and Monetization Readiness Plan

## Recommendation

Start public access as a free private beta with an optional donation link. Add accounts before payments. Add paid access only after the app proves daily value, admin-only content is fully hidden, and licensed resource rules are mature.

## Why

The app is becoming a serious Bible study platform, but the first public risk is not payment. The first risk is trust:

- users need confidence that Bible reading, study, notes, prayer, journal, sermons, and audio are stable
- admin-only acquisition, rights, and draft content must stay hidden from guests
- copyrighted resources must never leak into public access
- saved progress needs a clear local/synced story

## Access Layers

### Public Guest

Available without login:

- Bible Reader
- public-domain Library browsing
- selected public-domain books
- Passage Guide samples
- Theme Explorer samples
- public-domain commentary
- public-domain audio pilots after review
- feedback form

Hidden from guests:

- Library Acquisition Center
- Rights Management Center
- import queues
- permission-needed resources
- personal-use-only resources
- admin notes
- internal roadmap and planning
- unpublished audio/video

### Free Account

Add after guest beta stabilizes:

- saved notes
- highlights
- bookmarks
- reading progress
- listening progress
- prayer list
- journal
- sermon drafts
- study playlists
- sync across devices

### Supporter / Donation

Add early, but keep it gentle:

- "Support this ministry tool" donation button
- no locked Bible reading
- no pressure inside Scripture reading
- optional supporter badge later

### Paid Tier Later

Consider only after:

- user sync works reliably
- premium audio costs are understood
- licensed resource rights are approved
- admin/public separation is audited
- private beta users are asking for more

Possible paid value:

- premium AI/human-quality audio
- large licensed commentary/book bundles
- sermon and presentation workspace storage
- cross-device sync
- advanced exports
- church/team accounts

## Suggested Pricing Later

Do not launch payments immediately. When ready, test:

- Free: Bible, core public-domain study, limited local storage
- Supporter: $5/month optional donation
- Personal Pro: $9-12/month for sync, sermon workspace, premium audio quota
- Pastor/Teacher: $15-20/month for presentation/export tools and larger storage
- Lifetime public-domain edition: one-time $49-99, only if support burden is manageable

## Admin-Only Content Rule

Anything with these statuses must never appear in normal public Library/search:

- Permission Needed
- Contacted
- Negotiating
- Personal Use Only
- Do Not Import
- Needs Review
- Private admin draft

Only these should be public:

- Public Domain
- Approved
- Licensed

## Donation Button Timing

Add after:

1. private beta smoke test
2. admin-only route audit
3. feedback form works
4. Library and Bible Reader feel stable on mobile

Donation language:

> Father’s Business Bible Study is being built to help Christians read, study, pray, journal, and teach Scripture. If this tool helps you, you can support continued development.

## Copyright Permission Timing

Start asking now, but do not depend on approvals for launch.

Priority permission requests:

- modern KJV/audio Bible providers
- trusted Baptist publishers
- David Cloud / Way of Life
- John Phillips
- J. Vernon McGee rights holder
- sermon/audio ministries
- public-domain scan repositories when reuse terms are unclear

## Audio and Video

Recommended order:

1. public-domain LibriVox audiobook pilots
2. church-owned sermon/teaching audio with written permission
3. public-domain sermon recordings
4. licensed Bible audio
5. premium TTS
6. video sermons/teaching

Videos should stay private/admin draft until storage, bandwidth, and public rights are confirmed.

## Public Beta Gate

Before inviting broader public users:

- no visible admin-only tabs for guests
- no permission-needed resources in public search
- no unfinished import notes in public UI
- feedback works
- mobile Bible reading is easy
- Library search is fast
- audio stop/pause works
- exports do not break
- local data persistence is clear
- release notes and known limitations are current
