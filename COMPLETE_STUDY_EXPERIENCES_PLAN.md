# Complete Study Experiences Plan

## Direction

The app has enough raw library and commentary depth to feel overwhelming if users are left to hunt for material. The next product focus is complete study experiences: open a Bible passage and quickly see what to read, hear, study, teach, pray, journal, and save.

Scripture stays first. Every resource supports the KJV text instead of replacing it.

## Model Study Pack: Amos

Amos should be the first reusable model for a full Bible-book study ecosystem.

Current model scope:

- Amos 1-9 book overview
- Historical setting
- Timeline and background
- Map/place notes
- Kings and nations involved
- Key themes and major messages
- Repeated words and phrases
- Prophecy connections
- Christ connections
- Teaching outlines
- Sunday school questions
- Discussion questions
- Sermon outline starters
- Recommended commentaries
- Recommended library tools and books
- Exportable teaching notes
- Listening path for Bible chapters and commentary

Reuse this model later for:

- Romans
- Daniel
- Revelation
- Isaiah
- John

## Theme Explorer Foundation

Theme Explorer should become a signature study feature. A user chooses a theme and immediately sees related Scripture and reviewed study material.

Starter themes:

- Faith
- Grace
- Judgment
- Prayer
- Kingdom
- Shepherd
- Covenant
- Repentance

Each theme should eventually show:

- Key KJV verses
- Related passages
- Strong's entries where available
- Webster's 1828 definitions where useful
- Easton's / Smith's / Nave's entries
- Commentary links
- Library books
- Sermons
- Quotes
- Illustrations
- Applications

Build order:

1. Create reviewed theme metadata.
2. Connect themes to existing Bible references.
3. Connect themes to library resources and commentary search.
4. Add sermon/lesson export support.
5. Add user-saved theme collections.

## Reading Paths

Reading paths should guide users through the existing library instead of showing a wall of books.

Priority paths:

- New Believer
- Preacher / Teacher
- Prayer
- Baptist History
- Amos Study
- Romans Study
- Evangelism

Each path should include:

- Bible passages
- Recommended first books
- Commentary companion
- Listening playlist
- Journal prompt
- Teaching or application goal

## Audio Direction

Listening may become one of the highest daily-value features for users who work while listening.

Next audio priorities:

- Follow text while listening
- Paragraph highlighting
- Quote capture while listening
- Illustration capture while listening
- Add to sermon while listening
- Better saved voice fallback
- Future premium voice mode

Premium voice options to evaluate later:

- Browser Speech API
- OpenAI TTS
- ElevenLabs
- Cartesia
- PlayHT
- Human narration

## Content Growth Rule

Do not chase raw totals. Add content when it improves a complete study experience, fills a coverage gap, strengthens a reading path, or supports sermon and lesson preparation.
