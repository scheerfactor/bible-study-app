# Presentation Workspace Roadmap

## Purpose

The Presentation Workspace is planned, not built. Sermon preparation comes first.

## Philosophy

Scripture first. Slides support the Bible text and the message. They should not become the sermon.

## Planned Slide Types

- Title slide
- Scripture slide
- Main point slide
- Quote slide
- Application slide
- Closing slide

## Suggested Flow

1. Start from a saved sermon or lesson.
2. Read the passage.
3. Build the outline.
4. Create a slide outline from existing sermon sections.
5. Review every slide manually.
6. Present from tablet or computer.

## Design Tone

- Clean
- Warm
- Serious
- Readable
- Minimal
- Bible-centered

## Suggested Image Themes

- Open Bible
- Pulpit
- Study desk
- Simple church background
- Paper or parchment texture
- Location image when historically appropriate

## Future Features

- Slide builder
- Scripture slide generator using KJV only
- Sermon outline slide generator
- Quote slide builder with source/rights notes
- Application slide builder
- Presentation mode
- Timer
- Time remaining
- Next slide preview
- Speaker notes
- Confidence monitor
- Phone/tablet remote control
- Export research for Proclaim, PowerPoint, Keynote, and PDF

## Not Yet

- No full presentation engine.
- No Proclaim replacement yet.
- No paid image/media search.
- No copyrighted media import without permission.
- No AI-generated doctrine.
