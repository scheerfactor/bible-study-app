# Founding Ministry Partners Plan

This is an internal planning note only. Do not show a ministry publicly as a partner unless permission is final and approved for public mention.

## Purpose

As permissions are granted, ministries may eventually receive dedicated pages inside the Bible Study App. These pages should help users discover trusted resources while respecting copyright, attribution, and ministry relationships.

## Dedicated Ministry Page Fields

Each ministry page should include:

- ministry name
- short description
- official website link
- permitted resource types
- permission scope
- attribution wording
- public/private display status
- rights evidence location
- contact or follow-up notes
- resource review status

## Safety Rules

- Never imply endorsement or partnership unless the ministry explicitly permits public mention.
- Do not list copyrighted full content unless the permission scope clearly allows it.
- Separate metadata/link permission from full text, audio, video, transcript, excerpt, AI/TTS, and paid-access permissions.
- If permission is partial, show only the permitted items.
- If permission is pending, keep the record admin-only.
