# Author Curation Framework

## Purpose

Father's Business Bible Study should not compete by raw book count alone. The stronger goal is a curated library where users understand why a resource is present, how it should be used, and where the author fits historically and doctrinally.

This framework is for author and collection pages. It does not approve any author, ministry, book, sermon, audio, video, excerpt, image, chart, or quote by itself.

## Core Principle

Do not hide disagreements, and do not sensationalize them.

Explain:

- the author's background
- the author's theological perspective
- the author's strengths
- areas where the app's audience should use discernment
- recommended starting points
- which resources are core, historical, comparative, or still under review

Every public recommendation should point users back to Scripture as the final authority.

## Author Page Fields

Every significant author page should eventually include:

| Field | Purpose |
| --- | --- |
| Biography | Brief verified life and ministry summary. |
| Years lived | Helps users place the author historically. |
| Denominational background | Baptist, Anglican, Methodist, Presbyterian, Brethren, etc. |
| Theological perspective | Short summary of the author's general theological setting. |
| KJV posture | KJV-friendly, historically KJV-era, mixed, unknown, or not KJV-focused. |
| Baptist compatibility | How naturally the author fits Baptist doctrine and church practice. |
| Dispensational compatibility | How naturally the author fits dispensational study. |
| Strengths | What the author is most useful for. |
| Areas to explain | Differences, cautions, or historical context readers should know. |
| Recommended books | Best starting titles after rights/source review. |
| Suggested reading order | Simple path for new users. |
| Similar authors | Helps discovery without overwhelming users. |
| Resource labels | Core Library, Recommended, Historical Collection, Comparative Study, Needs Review, or Do Not Include. |
| Rights status | Public-domain, permission granted, permission needed, or unknown. |

## Perspective Ratings

Perspective ratings are orientation aids, not spiritual judgments.

Suggested scale:

| Rating | Meaning |
| --- | --- |
| 5 | Strong fit with the app's stated doctrinal basis. |
| 4 | Generally compatible with minor notes. |
| 3 | Useful with context or mixed fit. |
| 2 | Limited fit; use mainly for historical or comparative study. |
| 1 | Usually not a fit for normal recommendations. |
| Unknown | Not reviewed yet. |

Possible dimensions:

- KJV-friendly
- Baptist compatibility
- Dispensational compatibility
- Gospel clarity
- Scripture handling
- Historical reliability
- Devotional usefulness
- Preaching usefulness

Do not display these as final ratings until reviewed by a human reviewer.

## Example Caution Style

Use educational language:

> This author is historically important and often helpful, but some doctrinal assumptions differ from the app's Baptist and dispensational focus. Read with discernment and compare all conclusions with Scripture.

Avoid inflammatory labels unless a resource is being rejected internally for clear reasons.

Use this framework for:

- author profile stubs
- permission target review
- Library collection pages
- future public author pages
- related-resource recommendations
- caution labels in the Library

Keep `Needs Review` content out of public recommendations until rights, source quality, and theological review are complete.
