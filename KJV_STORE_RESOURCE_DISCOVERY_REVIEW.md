# KJV Store Resource Discovery Review

This note records The KJV Store as a resource discovery and permission-research source only. It does **not** approve any book, commentary, Bible note, cover image, audio, video, or product description for import.

Source reviewed: https://www.thekjvstore.com/christian-books/

## Summary

The KJV Store is useful for finding KJV-friendly categories, authors, publishers, and commercially available resources that may fit the Bible Study App audience. It should not be treated as a public-domain source. Most listed resources are retail products and require title-by-title copyright, publisher, and licensing review before any app use beyond a simple external link.

## Acquisition Use

Use The KJV Store to:

- identify high-value KJV-friendly titles
- discover rights holders and publishers
- find categories where the app is thin
- create permission request candidates
- compare our Library coverage against commercially useful study categories
- consider future affiliate links or official outbound purchase links

Do not use The KJV Store to:

- copy product descriptions
- copy cover images
- import digital book text
- import commentary notes
- assume a resource is public domain because it is sold there
- treat a product page as permission to reproduce content

## Recommended Next Actions

1. Add The KJV Store as a discovery/affiliate/permissions target.
2. Track selected products as permission-needed candidates, not public imports.
3. Prioritize public-domain alternatives where possible: Spurgeon, Murray, Bounds, Moody, Torrey, Matthew Henry, and older Larkin materials where the exact edition is rights-safe.
4. Prepare separate permission targets for modern controlled works: David W. Daniels, Doug Stauffer, Henry Morris, J. Vernon McGee, Chick Publications, Leadership Ministries, Northstar Ministries, and The Bible For Today.
5. Use the categories above to improve app browsing shelves without importing retail content.

## Guardrails

- Retail availability does not equal app redistribution permission.
- Cover images, product descriptions, commentary text, study notes, and audio/video require separate rights.
- Official links can be listed only after review and should point users to the rights holder or seller.
- Any paid, modern, or unclear work remains Permission Needed.
