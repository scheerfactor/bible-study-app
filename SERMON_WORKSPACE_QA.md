- Create sermon series.
- Search sermons by title, passage, theme, status, date, and content.
- Filter by sermon or lesson.
- Filter by status.
- Duplicate sermon drafts.
- Save locally for beta.
- Import reviewed study material into sermon prep notes.
- Add starter illustrations, quotes, and applications.
- Reorder sermon sections.
- Estimate sermon length.
- Set target preaching time.
- Export Markdown.
- Export plain text.
- Open print-friendly preaching notes.
- Use preaching mode with timer, time remaining, section progress, large text, dark/light mode, next section preview, and keyboard/tap navigation.
- Create sermon slides from the sermon workspace.
- Preview slides before service.
- Export PowerPoint for a church computer fallback.
- Use print/PDF fallback for preaching notes.

## iPad Preaching Readiness

Use this before preaching or teaching from an iPad.

- Open the sermon on the exact iPad and browser you plan to use.
- Confirm the whole sermon loads without signing out or losing local data.
- Set iPad brightness and disable auto-lock for the service window.
- Test large-text preaching mode from the pulpit distance.
- Test next/previous section taps with one hand.
- Confirm timer, time remaining, current section, and next section are readable.
- Export Markdown or text notes as a backup.
- Save a PDF or printed copy as a no-internet fallback.
- If using slides, export PowerPoint and keep a copy on the church presentation computer.
- If using app presentation mode, test it on the church Wi-Fi before the service.
- Do not rely on remote control for the first live service unless it has been tested in the actual room.

## Known Limitations

- Sermon workspace is local-storage first during beta.
- Cross-screen “send to sermon” buttons are not yet placed on every source screen.
- Import from study is available inside the Sermon Builder.
- Presentation engine is a beta MVP and should be tested before live use.
- PowerPoint export exists as the main slide fallback.
- PDF fallback should be created through print/save-as-PDF until full PDF export is promoted.
- Keynote and Proclaim-specific export are not complete.
- Illustration and quote libraries are starter placeholders, not a large reviewed database.

## Do Not Test Yet

- Fully automated sermon-to-slide generation without review.
- Untested church presentation remote control in a live service.
- Sermon cloud sync.
- AI sermon generation.
- Paid media or licensed slide assets.
