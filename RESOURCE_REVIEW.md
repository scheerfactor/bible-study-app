# Resource Review Workflow

## Purpose

This workflow turns resource intake into a repeatable review process. It applies to books, commentaries, dictionaries, sermons, audio, video, articles, charts, images, illustrations, hymns, quotes, and study notes.

No resource should become public simply because it is old, popular, online, or useful. It must be reviewed for rights, doctrine, quality, and usefulness.

## Required Inputs

Each review should begin with:

- title
- author or ministry
- publisher or rights holder
- publication year
- edition
- source URL
- file type
- intended use
- public/private status
- copyright or permission evidence
- doctrinal notes
- quality notes

## Review Board Steps

1. Intake the candidate resource.
2. Verify source, author, title, edition, and publication date.
3. Review copyright and permission status.
4. Compare doctrine against `DOCTRINAL_BASIS.md`.
5. Score the resource.
6. Assign a collection label.
7. Record warnings and recommended use.
8. Approve, reject, or hold for follow-up.

## Scoring Rubric

Scores use a 1-5 scale.

| Category | Score | Notes |
| --- | --- | --- |
| Biblical Accuracy |  | Does the resource handle Scripture faithfully? |
| Gospel Clarity |  | Is salvation by grace through faith clear? |
| Scripture Handling |  | Does it explain the text carefully without speculation? |
| KJV Friendliness |  | Does it respect the app's KJV-focused audience? |
| Baptist Compatibility |  | Is it compatible with Baptist doctrine and church practice? |
| Dispensational Compatibility |  | Is it compatible with the app's dispensational-friendly approach? |
| Practical Value |  | Will pastors, teachers, families, or readers actually use it? |
| Historical Importance |  | Is it important enough to include even with notes? |
| Source Quality |  | Is the source reliable, complete, and readable? |
| Rights Confidence |  | Are public-domain status or permissions documented? |
| Overall Recommendation |  | Final reviewer judgment. |

## Collection Labels

### Core Library

Fully aligned with the app's doctrinal basis and suitable for normal recommendations.

### Recommended

Strongly compatible and useful for most users, with a short note if needed.

### Historical Collection

Valuable historically but not necessarily a default doctrinal guide.

### Comparative Study

Useful for understanding other perspectives with clear context.

### Needs Review

Not ready for public use.

### Do Not Include

Rejected for rights, doctrine, quality, reliability, or usefulness concerns.

## Suggested Recommendation Thresholds

These thresholds are guidelines, not automatic approval.

| Result | Typical Scores |
| --- | --- |
| Core Library | Most categories 4-5, no major rights or Gospel concern |
| Recommended | Mostly 3-5, useful with limited notes |
| Historical Collection | Historically valuable but doctrinally mixed |
| Comparative Study | Useful for mature comparison but not default teaching |
| Needs Review | Missing source, rights, doctrine, or quality evidence |
| Do Not Include | Serious rights, Gospel, doctrinal, or quality concern |

## Author-Level Review

Author review is helpful, but final approval must be resource-specific.

An author may have:

- some public-domain works
- some copyrighted works
- some works suitable for core use
- some works useful only historically
- some works that should not be included

Do not approve an author's whole catalog automatically.

## Rights Rule

No response is not permission. Owning a physical book is not permission. A book being online is not permission. Text, images, charts, audio, video, transcripts, TTS narration, excerpts, and paid access may require separate permission.

## AI Rule

AI may help organize notes, detect missing fields, and draft summaries for review. AI may not approve a resource, invent doctrine, rewrite Scripture, or create a final doctrinal judgment.
