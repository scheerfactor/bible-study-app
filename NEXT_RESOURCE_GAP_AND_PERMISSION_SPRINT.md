Not yet assumed:

- Hosting audio/video files
- AI/TTS narration
- Paid subscription inclusion

Next action:

Make Northstar the model permissioned ministry page before seeking broader permissions.

## Safety Rules

- No copyrighted text enters the public Library without written permission.
- Public-domain source, edition, and publication date must be documented.
- Do not create duplicate public cards for audiobook/text versions of the same work.
- Audio/video is private review by default.
- Ministry permission for links/excerpts does not automatically include file hosting, resale, AI, TTS, or subscription rights.
